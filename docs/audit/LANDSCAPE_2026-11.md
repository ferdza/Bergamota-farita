## 0. Method, evidence tags and limits

Sources, in order of weight:

- **V = verified in repo**: a file was read in a local read-only clone under
  `/tmp/claude-0/-home-user-Bergamota-farita/f3a6144f-169f-5d24-8f9c-9f901920a199/scratchpad/refs/`
  (`hackios-xnu-kernel` = `oosexgang_hackios-xnu-kernel`, `UniXNU_UniXNU`, `LMasterPiec3_ios-sweet`, `MakrSas_ios-topaz`,
  `IOS4Amethyst_AdrenoMetal`, `urielc918_ios-switch`, `ry-diffusion_Chlorophyll`). Note the clones are snapshots: topaz is dated
  2026-10-22 (local HEAD), UniXNU 2026-11-12, so topaz has certainly moved on.
- **R = README / docs claim** read on the web (WebFetch of a repo page or hackiosx.dev) but not checked against code.
- **S = GitHub search metadata** (`gh api search/repositories`: pushed_at, licence, stars, description). Reliable for
  existence/date/licence, says nothing about whether the code works.
- **P = press, P? = rumour**: Android Authority 2026-10-21 (ios-sweet, official forks Redmi Note 12 Pro and LG V60, in-progress OnePlus 7T, Redmi 5 Plus, Galaxy S23 Ultra), Windows Latest 2026-10-27 (SmuOS UniXNU-zeta: iOS 26.5.2 on Surface Duo 2, SD888, about 37 fps, Wi-Fi/BT N/A, Turnip), TechEBlog about 2026-11-02 (Poco F1, snippet only). Press repeats README claims; treat as R.
- A claim from one project's page about another project (for example HakiOS's comparison table) is R at best.

Limits of this pass: the repo REST API for individual repos (`gh api repos/OWNER/NAME`) is refused for everything except
search, so licence/last-push come from search results. `projects.html#community-ports` of hackiosx.dev was fetched (R).
Telegram, X, reddit and YouTube were not reachable/searched yet (open items).

## 2. Per-subsystem best known implementation

Licence rule of thumb for our tree (xnu patches are APSL-2.0; Renegade, Enxerto and the apps are ours):

- **Can adapt code**, keeping notices: APSL-2.0 sources (HakiOS `xnu/hakios.patch`, `xnu/files/`, `drivers/`; the xnu patches of ios-sweet, topaz and ios-switch) and permissive MIT / BSD-2-Clause-Patent sources (ios-sweet shim and tools, HakiOS userland and `hakios-metal/`, AdrenoMetal, Adreno740, Chlorophyll's AIR files, the UniXNU main repo).
- **Idea-only** (read, do not copy): anything that embeds or derives from Linux GPL-2.0 code (HakiOS `wifi/lx` LinuxKPI headers, UniXNU Ath12kWifi which runs Linux v7.0.14 ath12k/mac80211, btqca-derived QcaBluetooth), metal2vulkan (GPL-2.0-or-later OR LGPL-3.0-or-later), Snapintosh GPL-2.0 files, hekate (GPLv2), and every repo whose licence is absent or NOASSERTION (LMasterPiec3/ios-sweet has no LICENSE at root, edi194/ios-fajita, most UniXNU device repos, flame, sailfish). "No licence" means all rights reserved: ask the author.
- UniXNU component repos other than AdrenoMetal and Adreno740 (MIT per search metadata) have **no licence verified by me**; the main repo is BSD-2-Clause-Patent (V).
- ath11k itself is BSD-3-Clause-Clear (V, HakiOS THIRD_PARTY_LICENSES.md) but the Linux framework around it is GPL-2.0: treat as idea-only unless counsel says otherwise.
